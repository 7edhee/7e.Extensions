# Security Policy

## Supported versions

The latest version on the `main` branch is the currently supported version.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue before it has been reviewed. Use GitHub's private vulnerability reporting or security advisory workflow for this repository when available. If that workflow is unavailable, open a minimal issue requesting a private reporting channel and do not include exploit details.

When reporting, include:

- The affected extension and version.
- The affected file or behavior.
- Clear reproduction steps.
- The potential impact.
- Any suggested mitigation.

Please allow time for assessment and remediation before public disclosure.
